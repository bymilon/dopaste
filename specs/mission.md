# Mission

Dopaste is minimal Markdown pastebin.

## Promise

- Write Markdown.
- Save paste fast.
- Share permanent URL.
- Read rendered output.

## Non-Goals

- No accounts.
- No social features.
- No feeds.
- No teams.
- No complex editor.
- No publishing platform scope.

## Product Rules

- Speed over feature count.
- Simple URL sharing over workflows.
- Markdown-first, rendered read view second.
- Mobile works, desktop efficient.
- Public paste behavior clear.

## Success

- User can create paste in seconds.
- Shared paste loads fast globally.
- UI stays quiet.
- Ops stay low.
